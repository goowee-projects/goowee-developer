# Goowee Developer
Develop Goowee applications with AI


1. Create a new Grails project (select at least `Java 21` and `Grails 8.0.0`): https://start.grails.org/
2. Copy the `.agents` folder to the project root
3. Open the project in your coding agent and start with a prompt such as: `Build a Goowee bookstore application for Books and Authors`.

## Some Prompts

### Initialize
This configures the basic setup for a Goowee applications
```aiignore
Initialize a Goowee application.
```

### Domain Classes
This will create the corresponding service as well.
```aiignore
Create the domain class Publisher. 
```

### Controllers
```aiignore
Create a Controller for books. Make it a favourite feature.
```

### Build CRUDs
```aiignore
Create a CRUD for the domain Book with title, author, and publication date.
```

### Bootstrap a Goowee application
```aiignore
Initialize a Goowee application.
Create a CRUD for the domain Book with title, author, and publication date.
Create a CRUD for the domain Author with name and age.
Make books as a favourite feature.
Create 73 records of mockup data per each domain class.
Credits for the app: Project Managers: Gianluca Sartori; Software Developers: Francesco Piceghello, Gianluca Sartori.
```
